# 子代理提示詞模板

完整版使用。把 `{日期}`、`{股票}`、`{代號}`、`{基準價}` 換成實際值。6 個提示詞在同一回合一次發出，`subagent_type` 用 `general-purpose`，`run_in_background: true`。

## 共同開頭

```
你是投資團隊的「{角色}」。今天是 {日期}。標的：{股票}（{代號}）。基準價：{基準價}（請標明為盤中價或收盤價）。

你的負責範圍：{範圍}。請用 WebSearch（mode 用 standard，必要時 extended；先用 ToolSearch "select:WebSearch" 載入）查最新公開資料，重點：
{重點清單}

只做你自己範圍的分析。資料互相矛盾時標明。查不到的資料要明說，不要編造。推估值要標示為推估。不要寫任何檔案。
```

## 共同輸出格式（繁體中文，600 字內）

```
立場：偏多／中性／偏空（擇一），信心：1–5
核心論點：3–5 點，每點附關鍵數字
主要風險：2–3 點
對班長的一句話建議：
關鍵數據表：項目｜數值｜來源 URL
資料缺口：查不到或不確定的項目
```

各角色在上面格式外額外加一行：

| 角色 | 額外欄位 |
|---|---|
| 技術面 | 關鍵價位：壓力 1/2、支撐 1/2 |
| 總體經濟 | 可能翻轉的事件（附日期） |
| 市場情緒 | 情緒溫度：極度恐慌／恐慌／中性／樂觀／極度樂觀 |
| 風險管理 | 風險參數：停損價、部位上限、風險報酬比 |
| 投資策略 | 短／中／長線策略、進場條件與配置、催化劑時間表（日期｜事件） |

## 各角色重點清單

### 基本面

- 最近 3 季以上的單季營收、毛利率、營益率、EPS；**最新單月營收**；累計 EPS
- 法說會管理層對下一季與明年的展望
- **最新一季的存貨金額與週轉天數**（查不到就明說，不要用舊季度冒充）
- 估值：本益比、股價淨值比、市值概算、股利政策
- 競爭力：市佔、同業比較、產品組合
- 景氣循環位置與估值陷阱風險

### 技術面

- 近期每日開高低收、漲跌停、成交量；52 週高低點與日期
- 近一年主要波段與回檔
- 均線位置、乖離、KD／RSI／MACD（查不到就推估並標明）
- 支撐壓力：前波高低點、跳空缺口、成交密集區、公司庫藏股區間
- 量價關係：是否量縮止跌

### 總體經濟

- Fed 最近決議、利率區間、委員分歧、下次會議預期
- 通膨、美元指數、美債殖利率
- 本國匯率、外資進出、央行動向
- 全球景氣與產業需求、資本支出疑慮
- 政策面：出口管制、關稅
- 以上對該產業與個股的傳導方向

### 市場情緒

- 三大法人最近買賣超與持股變化
- 融資融券、借券賣出餘額
- 外資券商最新評等與目標價（升降評）
- 重大新聞：庫藏股、產業價格、**當天大盤與族群走勢、個股異動原因**
- 市場氛圍：是否出現「好消息不漲」

### 風險管理

- 近一年最大回撤、近期漲跌停頻率
- 歷史景氣反轉時該股的跌幅（壓力測試參考）
- 外資目標價的樂觀／基本／悲觀情境，換算上檔、下檔與風險報酬比（**注意情境名稱不要寫錯**）
- 財務緩衝：現金、存貨與跌價風險、負債
- 毛利率下行對獲利的敏感度
- 給出停損價（附理由）、單一持股上限、分批原則

### 投資策略

- 產業景氣循環位置與未來幾季價格預測（標明來源與範圍）
- 催化劑時間表：月營收、法說、除息、庫藏股期限、產業展會
- 長期成長敘事 vs 短期需求轉弱
- 週期股操作原則：何時低本益比反而是賣點
- 同族群替代標的比較
- 短（1 個月）、中（1–2 季）、長（1 年以上）策略與具體進場條件
